プライバシーポリシー

「新作ゲーム紹介 投稿ツール」（以下「本ツール」）における情報の取り扱いを説明します。

1. 本ツールの目的

本ツールは、YouTube チャンネル「新作ゲーム紹介チャンネル」の運営者が、自分で作成した動画を自分のチャンネルに投稿するためだけに使う個人用ツールです。

2. 取得する情報

本ツールは Google の OAuth 認証を通じて、運営者自身の Google アカウントについて次の権限のみを使います。

  • YouTube への動画のアップロード（youtube.upload）
  • 投稿先チャンネル名の確認（youtube.readonly）

運営者以外の個人情報は取得しません。

3. 情報の保存と利用

認証で得たトークンは、運営者のパソコン内にのみ保存し、動画の投稿以外には使いません。外部のサーバーへの送信、第三者への提供、販売は行いません。

4. Google API サービスの利用について

本ツールは YouTube API Services を利用しています。利用にあたっては YouTube 利用規約 および Google プライバシーポリシー が適用されます。アクセス権は Google アカウントの権限設定 からいつでも取り消せます。

5. お問い合わせ

新作ゲーム紹介チャンネル までご連絡ください。
